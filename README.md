# ЛЦСИ · Демонстрационная копия

Адаптивный сайт стоматологии на React, TypeScript и Vite. В демо доступны главная страница, страницы услуг, карточки специалистов, прайс и интерфейс формы записи.

Форма принимает только вымышленные данные для проверки интерфейса. Заявки остаются в памяти страницы и сбрасываются после демонстрации. Прайс локальный и содержит демонстрационные цены. Вместо фотографий установлена нейтральная иллюстрация.

## Локальный запуск

```bash
npm ci
npm run dev
```

Сборка `npm run build`. Для просмотра собранной версии используй `npm run preview`.

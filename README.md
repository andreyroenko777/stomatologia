# ЛЦСИ · Сайт стоматологии

[Открыть сайт](https://www.lcsi.ru/)

Сайт на React, TypeScript и Vite. В проекте есть адаптивная главная страница, каталог услуг, карточки специалистов, прайс и форма записи.

## Интерфейс

- Навигация по услугам и многоуровневое меню.
- Карточки специалистов, отдельные страницы услуг и мобильная панель действий.
- Модальное окно записи и адаптивная вёрстка.

Публичная страница проекта содержит ссылку на действующий сайт. Исходный репозиторий закрыт.
